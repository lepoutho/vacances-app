# Installer Vacances comme une appli — guide par navigateur

Aide-mémoire pour la vidéo PWA séparée. Plutôt que des étapes de menu
figées (qui bougent d'une version de navigateur à l'autre et
deviennent fausses avec le temps), voici pour chaque navigateur la
**phrase clé à taper dans un moteur de recherche** — elle mène
toujours à la documentation ou aux tutoriels à jour, contrairement à
des captures d'écran ou des libellés de menu qui datent vite.

URL à utiliser dans toutes les démos : `https://vacances.teodul.fr`

---

## 📱 iPhone / iPad

- **Safari** (le principal sur iOS) → *"ajouter à l'écran d'accueil
  safari iphone"*
- **Chrome, Brave, Firefox, Edge sur iOS** → *"ajouter à l'écran
  d'accueil [nom du navigateur] iphone"*
  (sur iOS, tous ces navigateurs passent par la feuille de partage du
  système, pas par un menu qui leur est propre — donc la recherche
  ramène souvent vers la même manip que pour Safari)

## 🤖 Android

- **Chrome** (le plus répandu) → *"installer application chrome
  android"* ou *"ajouter à l'écran d'accueil chrome android"*
- **Samsung Internet** (courant sur téléphones Samsung) → *"ajouter
  à l'écran d'accueil samsung internet"*
- **Brave** → *"ajouter à l'écran d'accueil brave android"* — c'est
  celui qui a posé problème lors des tests, le menu n'est pas très
  visible.

## 🖥️ Ordinateur

- **Chrome** → *"installer une pwa chrome ordinateur"*
- **Edge** → *"installer une application edge windows"*
- **Safari sur Mac** (depuis macOS Sonoma) → *"ajouter au dock
  safari mac"*
- **Firefox** → ne propose pas d'installation PWA native ; un
  signet classique reste la seule option.

---

## Notes pour la vidéo

- Privilégier dans l'ordre : **Safari iOS** (le plus probable chez la
  majorité des spectateurs sur iPhone), puis **Chrome Android**, puis
  un aperçu rapide desktop si le temps le permet.
- Bien montrer l'aperçu **avant** de valider à chaque fois : c'est le
  moment où on voit si la vraie icône (avion orange) apparaît ou pas
  — c'est ça qui prouve que ce n'est pas "juste un raccourci".
- Une fois l'icône sur l'écran d'accueil, l'ouvrir pour montrer le
  mode plein écran (pas de barre d'adresse, ça ressemble à une vraie
  appli) — c'est l'argument le plus parlant visuellement.
